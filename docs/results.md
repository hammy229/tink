## Leakage check

Shuffled labels should score at chance. If they scored higher, the evaluation itself would be leaking.

| Benchmark | Shuffled accuracy | Chance |
|---|---|---|
| Spontaneous sounds, taught across days, tested on another day | 18.1% | 20.4% |
| Spontaneous sounds, taught in one sitting, tested on another day | 35.1% | 35.2% |
| Dysarthric speech, any session | 18.8% | 20.0% |
| Control speakers, any session | 20.5% | 20.0% |
| Dysarthric speech, taught in one sitting, tested on another day | 24.3% | 20.0% |
| Control speakers, taught in one sitting, tested on another day | 19.1% | 20.0% |

This only proves the scoring doesn't leak. It can't catch session or mic effects, which survive a shuffle; the tested-on-another-day benchmarks are what address those.
